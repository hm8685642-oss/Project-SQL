# 📊 Project SQL: Basic to Advanced Database Queries

## 📌 Overview
This repository contains a structured collection of ready-to-run SQL scripts designed for direct execution in relational databases. It covers essential data querying, data cleaning, complex relational joins, and advanced analytical operations used in business and data analysis.

---

## 🗂️ SQL Concepts Covered

### 1. Basic Operations (Data Retrieval & Filtering)
* **`SELECT` & `DISTINCT`:** Extracting specific columns and identifying unique records across single and multiple columns.
* **`WHERE` Clause:** Filtering datasets using comparison operators (`=`, `!=`, `<`, `>`), logical operators (`AND`, `OR`, `NOT`), `IN`, `BETWEEN`, and pattern matching (`LIKE`).
* **`ORDER BY` & `LIMIT`:** Sorting query results and restricting output rows for top-N analysis.

### 2. Intermediate Operations (Aggregations & Joins)
* **Aggregate Functions:** Summarizing data using `COUNT()`, `SUM()`, `AVG()`, `MIN()`, and `MAX()`.
* **`GROUP BY` & `HAVING`:** Grouping records by categorical attributes and filtering aggregated metrics.
* **Relational Joins:** Combining multiple tables using `INNER JOIN`, `LEFT JOIN`, `RIGHT JOIN`, and `FULL OUTER JOIN`.

### 3. Advanced Analytics
* **Conditional Logic (`CASE WHEN`):** Creating custom buckets, status flags, and dynamic data categorizations.
* **Subqueries & CTEs (`WITH` Clause):** Writing modular, readable, multi-step queries for complex filtering and derived tables.
* **Window Functions:** Performing row-level analytical calculations using `ROW_NUMBER()`, `RANK()`, `DENSE_RANK()`, `LEAD()`, `LAG()`, and running totals (`SUM() OVER()`).
